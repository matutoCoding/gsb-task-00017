# 标签合规拼版台

从**标准段落库**拼产品包装标签：按国家/品类/规格维护段落，拼版时按选定市场的规则排配料、标过敏原；
两段说法打架先拦下；改一段之前先摆清牵动的产品、在印/在途数量和召回成本；改印/贴补/召回分别处理；
每次改动留时间、原因和影响清单，旧版本永久备查。

## 运行

零依赖（Python 3.10+ 标准库）：

```bash
python3 server.py          # 默认 8088，可用 PORT=9000 python3 server.py
# 打开 http://localhost:8088
```

数据存在 `data/db.json`（JSON 文件库，原子写）。界面右上角「重置演示数据」可恢复种子。

## 七个功能点对应

1. **标准段落库**：段落按 `国家 × 品类 × 包装规格 × 指定产品` 四维标适用范围；空维度表示通用
   （见 `server.py:applicable`），段落库页可按类型/市场筛选、新建。
2. **按市场规则拼版**：配料按重量降序；过敏原 CN 括号标注、EU 在配料中加粗（1169/2011）、
   US 单独生成 `Contains:` 声明（FALCPA），规则在 `MARKET_RULES` 中。
3. **冲突先拦后拼**：互斥组（如「转基因/非转基因」声明同组不能同版）、警示语口径冲突
   （「请勿食用」vs「严禁食用」）、适用性不匹配三类硬拦截；过敏原未覆盖、缺必备段落为提醒。
   有拦截时不能建版/定稿。
4. **改版影响预览**：`POST /api/segments/<sid>/revise` 不带 `confirmed` 时返回 202 +
   影响清单：引用该段的已定稿标签 → 产品、已印数量、在途数量、预估成本。
5. **三档处置建议**：警示语/过敏原/配料 → **必须召回**（¥0.55/件）；产地/生产商 → **贴补丁**
   （¥0.08/件）；其余 → **下次改印**（无处置成本）。向导里可逐标签改选，成本实时重算。
6. **审计与旧版**：修订先归档完整旧版（正文/配料/版本/原因/操作人），审计记录时间、原因、
   每个受影响标签的建议与最终处置；「改动记录」页可回溯。
7. **整份预览**：标签按段落类型固定顺序排版，未定稿段落打橙色「未定稿」标，冲突/提醒置顶，
   含未定稿段落或冲突时不能定稿（只能存草稿）。

## API 速览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/meta` | 市场规则、段落类型、过敏原词库 |
| GET | `/api/products` · POST `/api/products` | 产品与在印/在途库存 |
| GET | `/api/segments?country=&type=&product=` | 段落库 |
| POST | `/api/segments` | 新建段落 |
| GET | `/api/segments/<sid>` | 段落 + 全部历史版本 |
| GET | `/api/impact/<sid>` | 改版影响分析 |
| POST | `/api/segments/<sid>/revise` | 首次 202 影响清单；`confirmed:true` 才真正改版 |
| GET | `/api/labels/candidates?product=&country=&type=` | 某槽位的候选段（按特异性排序） |
| POST | `/api/labels/preview` | 不落库的整份预览/冲突检查 |
| POST | `/api/labels` | 建标签（有冲突返回 409） |
| POST | `/api/labels/<lid>/finalize` | 草稿定稿 |
| GET | `/api/audit` | 改动时间线 |

## 文件

- `server.py` — HTTP 服务、数据与全部业务规则（无第三方依赖）
- `web/index.html` · `web/style.css` · `web/app.js` — 单页界面
- `data/db.json` — 运行后生成的数据文件
